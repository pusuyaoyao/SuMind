# 界面开发约定

- 不使用 WPF 默认的虚线焦点框或大面积虚线选区；新增控件和模板时也要遵守。
- 键盘操作仍须有清晰可见的焦点提示。默认使用系统强调色的实线焦点框，自定义控件可采用适合控件的实线提示，并兼顾高对比度。
- 页面滚动容器不显示覆盖整个内容区的焦点框，保留键盘滚动能力；可交互控件应提供各自的焦点提示。
- 修改界面后检查鼠标操作和 Tab、方向键等键盘操作，并验证浅色、深色及高对比度表现。

- 新增组件、页面和控件必须与 SuMind 现有界面风格保持一致，包括配色、字体、间距、圆角、边框和交互状态；优先复用已有样式及主题资源，避免直接使用与界面不协调的默认控件外观。
- 新增或调整控件时，同时检查浅色、深色、悬停、按下、禁用和键盘焦点状态。
