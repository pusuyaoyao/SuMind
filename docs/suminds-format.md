# .suminds 容器（实验版）

这是尚未发布的第一版草案，不能用于执行网络下载的代码。多字节整数为小端序：8 字节 ASCII `SUMINDS1`；4 字节有符号清单长度；UTF-8 JSON 清单；按清单顺序连续排列的未压缩文件数据。清单包含 `Id`、`Version`、`Files`，每个文件包含相对 `Path`、字节 `Size` 和十六进制 `Sha256`。

`SuMind.PackageTool` 支持 `pack <ID> <版本> <输入目录> <输出.suminds>`、`keygen <私钥.pem> <公钥.pem>`、`sign <包> <私钥.pem> <签名>`、`verify <包> <签名> <公钥.pem>`。`extract <包> <新目录> <预期ID> <预期SHA256>` 仅用于开发验证，不验签，不能用于安装不可信包。正式安装使用 `PackageInstaller.Install`。

签名为 RSA-PSS / SHA-256，密钥至少 3072 位，对包完整原始字节签名；签名为独立二进制或 Base64。主程序必须内置经独立验证的公钥（SubjectPublicKeyInfo PEM），不能信任与拓展一起下载的公钥。SHA-256 本身不能证明发布者身份。生成的私钥未自动加密或设置权限，必须安全保管，禁止上传 GitHub；密钥轮换和吊销需要后续主程序更新。

安装器在同一个文件句柄上验签和校验，再写入暂存目录，移动到独立版本目录，最后替换当前版本指针，保留旧版本。`ActivateVersion` 可以回滚。`Uninstall` 仅删除安装根下对应拓展目录；调用方应先停止拓展进程，并将用户设置保存在安装根以外。安装、回滚和卸载使用独占文件锁，争用时立即失败；状态读取不持锁。

进程中断可能留下暂存目录、无引用版本或卸载残留，当前不会自动清理。安装器不会启动程序或自动判断是否回滚。安装根必须由主程序控制，不能是非可信位置。还需更多安全审查、异常测试以及独立进程生命周期设计。当前格式不保证兼容未来版本。
